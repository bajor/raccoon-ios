# Context and glossary

- **Artifact:** a frozen PR explanation plus its full Git source assets and diagrams.
- **Catalog:** the authoritative list of artifacts from one imported repository.
- **Generation:** a complete replacement snapshot of one PR.
- **Thread:** an explained functional mechanism spanning paths and commits.
- **Stage:** one commit's explanation within a thread.
- **IndexedDB:** the browser's transactional local database for imports and progress.
- **PWA:** progressive web app, a static reader optionally installed to the Home Screen.
- **CSP:** Content Security Policy, browser rules limiting executable content and requests.
- **GitSync:** an existing external iOS Git application, not a Raccoon component.
